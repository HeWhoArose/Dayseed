# Dayseed

**Your progress is more than your streak.**

Dayseed is an Android-native, offline-first habit and micro-journal application built with Kotlin and Jetpack Compose. It is designed for people who want to build consistency without being shamed when life interrupts them.

## Product scope and source components

The current repository contains native Kotlin/Jetpack Compose source for Today, History, Insights, Settings, Add/Edit Habit, and Journal Editor screens, plus source components such as HabitCard, GrowthMark, ComebackCard, and ReflectionCard. Their presence in source is not proof that the app builds, passes tests, or behaves correctly on a device.

The product and planning documents define the intended initial-v1 scope: quantity/duration/check-off tracking, independent text journaling, history correction, local insights, approved 14-/30-day comeback triggers, local journal search, reminders, readable journal export, portable backup/restore and user-controlled deletion. The current source contains substantial v2 persistence and application logic, but several complete user journeys and Android runtime behaviours remain incomplete or unverified. **For any AI-assisted continuation, start with [AGENTS.md](AGENTS.md) and the [Continuation Handover and Decision Protocol](docs/32-CONTINUATION-HANDOVER.md)**; they explain decision authority, delegated defaults, the current Stage A approval, the separate Stage B/C/D gates, and the exact next steps. ## Technology Stack

The project declares a native Android/Kotlin + Jetpack Compose stack with SQLiteOpenHelper, a repository, ViewModel/StateFlow, and Gradle build configuration.

- **Platform configuration:** minSdk 26, targetSdk 36, compileSdk 36
- **Language/tooling declarations:** Kotlin 2.2.10; Gradle 9.3.1; Android Gradle Plugin 9.1.1; Java 21
- **UI Toolkit:** Jetpack Compose + Material 3
- **Architecture:** ViewModel/StateFlow and repository-based structure
- **Local persistence:** SQLiteOpenHelper (`DATABASE_VERSION = 2`, 12 tables, fail-closed v1-to-v2 migration in source; v2-to-v3 migration scheduled for Phase 1).
